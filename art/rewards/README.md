# Wonder Sparks illustration set

Created 2026-10-25 for Wonder Lab Adventures. These editable SVG source files
were authored for this task from original geometric paths, shapes and palettes.
No downloaded assets, stock icons, existing character designs, external images,
font files or licensed character art were used. This provenance statement does
not constitute trademark clearance or a claim of exclusive rights in
AI-assisted artwork.

The shared visual language uses warm navy, mint, amber, cream and soft plum;
rounded inventor machines; faceted crystals; and four-point glints. Images carry
SVG titles/descriptions and contain no scripts, external references or text
requiring a font. Runtime labels remain accessible HTML outside the illustrations.

| Source | Purpose |
|---|---|
| `spark.svg` | Faceted Wonder Spark progress resource |
| `beam.svg` | Straight-path science card, illustrated source and lamp |
| `mirror.svg` | Flat mirror turning one ray through a right angle |
| `relay.svg` | Four reflections guiding a winding path |
| `compare.svg` | Two board configurations and an observation notebook |
| `angle.svg` | Equal reflection angles measured from the perpendicular normal |
| `model.svg` | Simplified ray diagram and a flat mirror as a reminder of model limits |
| `goggles.svg` | Transparent golden Inventor Goggles overlay |
| `bot-mint.svg` | Mint Circuit robot suit |
| `badge-orbit.svg` | Transparent Orbit Maker badge and coral ribbons |
| `bot-plum.svg` | Starlight robot suit with an original star cap |
| `moonlit.svg` | Moonlit Observatory decorative lab scene |
| `greenhouse.svg` | Glass Garden decorative lab scene |
| `nova.svg` | Nova, an original crescent-antenna robot companion |
| `mission.svg` | Discovery mission notebook icon |
| `progression-hero.svg` | Wide illustrated progression banner with quiet space for HTML heading |

`goggles.svg` intentionally uses a transparent 180×100 viewBox for layering on
the helper; `badge-orbit.svg` is a transparent square. The other cosmetics and
Nova include a rounded presentation tile. Six concept cards and both themes
use 240×160 postcard compositions. The hero is 760×260.

These are playful diagrams of the game's simplified two-dimensional flat-mirror
model. They are not instructions for physical experiments or proof of learning
outcomes. The themes are decorative and do not introduce new science mechanics.
